# Learnings

更新日: 2026-07-06

このディレクトリは、`nexttree-tools` の開発中に得たプロジェクト固有の知見を残す場所である。

## 方針

- 別ユーザー、Codex、Claude Code、その他のAIエージェントでも読める Markdown として残す。
- 一時メモではなく、後から参照する価値がある内容だけを書く。
- 仕様に昇格する内容は、対応する `dos/` ファイルへ反映する。
- AI作業手順に関わる内容は、必要に応じて `.ai/` にも反映する。

## 禁止事項

- 秘密情報
- 個人情報
- token
- 鍵
- `.env` の実値
- Firebase project の機密設定値
