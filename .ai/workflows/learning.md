# Learning Workflow

更新日: 2026-07-06

## 目的

セッションで得たプロジェクト固有の知見を、別ユーザーや別AIエージェントでも参照できる形で残す。

## 保存先

- プロジェクト固有の学び: `dos/learnings/`
- 仕様に昇格する内容: 対応する `dos/` ファイル
- AI作業手順に関わる内容: `.ai/` 配下

## 手順

1. 学びが一時的な作業メモか、継続参照すべき知識か判断する。
2. 継続参照すべき場合は `dos/learnings/` に Markdown で記録する。
3. 仕様や設計判断に影響する場合は、該当する `dos/` ファイルにも反映する。
4. Codex の `/learn` など外部スキルは、使える場合だけ補助として利用する。

## 注意

秘密情報、個人情報、token、鍵、実値の設定は記録しない。
